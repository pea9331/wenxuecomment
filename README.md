# 文学问答：收藏与输入法容错合并更新
面向中文阅读讨论的个人项目，现有账号、提问、回答、分享、个人主页功能。
本包是已有网站的增量更新，不能单独部署成完整站点。

## 本轮解决
- 个人账号收藏问题、取消收藏、查看收藏列表。
- 首页“查看收藏”直接进入我的主页收藏页，移除该入口的占位弹窗。
- 中文短词同音字搜索，兼容输入法选择了同音字的部分情况。
- 关键词、文字编辑距离、拼音候选统一排序：精确结果优先。
- 保留回答每10秒自动更新及草稿保护。
- 合并脚本可重复执行，已有收藏不删除。

## 简短网页验收
- 发布一个测试问题，标题包含“鲁迅与汪曾祺”，书名写“故乡”。
- 分别搜“鲁迅”“鲁讯”“汪曾棋”“故香”，应能找到此问题。正确输入的精确结果排在相似候选前。
- 搜一段正文的准确片段，也应命中；完全无关词应显示无结果。
- 打开测试问题收藏，刷新确认仍已收藏；从首页“查看收藏”进入列表，再取消收藏。
- 退出登录，收藏列表不显示上一账号内容，问题页收藏按钮引导登录。
- 搜索返回、回答发表/编辑/删除及自动更新继续可用。

## 搜索怎样实现
PostgreSQL运行参数化只读函数。文字容错复用官方fuzzystrmatch扩展，拼音数据来自MIT授权的pypinyin 0.55.0；完整许可与来源在licenses目录。
预生成26703个字的字音词典，覆盖U+3400—U+9FFF范围中有读音的字，保留字典提供的多音字读音。
部署后在数据库内完成搜索，不调用Python服务、不下载浏览器模型、不需要模型Key或外部拼音服务。
新问题或编辑后的标题与书名直接参与查询，不维护一份容易过期的搜索副本。

排序规则：
1. 完全匹配书名/标题；
2. 包含关键词的书名/标题；
3. 包含关键词的正文；
4. 同音字匹配的书名/标题；
5. 编辑距离近似匹配的书名/标题；
6. 同一等级按问题发布时间倒序。

## 搜索实际边界
- 拼音匹配只用于2—16字关键词及标题/书名，忽略声调，可能召回意思不同的同音词，不能认定候选一定正确。
- 字典多音字读音取并集，没有上下文消歧；未覆盖拼音字典之外的字。
- 文字编辑距离用于3—12字关键词，允许一次增字、漏字或替换。
- 正文保留完整片段包含匹配，不在长正文上逐窗口计算拼音和编辑距离。
- 不支持所有输入法错误；拼音输错、方言读音、同义改写未保证识别。
- 这仍不是语义搜索，未接入中文向量模型。
- 现阶段面向小规模私测，未完成大数据性能或多人并发压测。

## 账号与数据权限
Supabase Auth负责凭据，业务表不保存明文密码。
问题和回答公开阅读；收藏仅本人可读/新增/删除。
收藏user_id显式绑定提交时账号，并由RLS验证等于auth.uid()，客户端无UPDATE权限。
复合主键防重复；已收藏再次收藏、已取消再次取消可安全重试。
问题被删除时其收藏和回答按外键规则清理。
公开拼音表只有静态字音数据，普通用户只读，启用RLS，不含用户隐私。
所有用户文字仍用textContent展示。
